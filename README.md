# Маркообразные Новосибирск — тестовое PWA

Тестовая информационная версия клуба на бесплатном GitHub Pages.

## Установка

После включения GitHub Pages ссылка будет:
https://kiberdoker-pixel.github.io/markoobraznye-app/

* Android / Chrome: три точки → «Установить приложение» или «Добавить на главный экран».
* iPhone / Safari: «Поделиться» → «На экран Домой» → «Добавить».

Новости обновляются через GitHub Issues при повторном открытии приложения или нажатии «Обновить». Повторно устанавливать PWA и скачивать APK не нужно.

## Добавление новостей для 5 тестировщиков

1. Откройте форму: https://github.com/kiberdoker-pixel/markoobraznye-app/issues/new?template=news.yml
2. Напишите текст в поле «Текст новости», добавьте изображение через интерфейс GitHub при необходимости.
3. Укажите заголовок с префиксом [НОВОСТЬ].
4. Если публикацию сделал владелец GitHub-аккаунта kiberdoker-pixel, она видна сразу после обновления ленты в приложении.
5. Публикации других авторов появятся только после добавления метки published владельцем либо редактором репозитория. Метку можно создать в разделе Issues → Labels.

Это временная тестовая схема: настоящий защищённый вход по почте и общую панель управления сделаем на российском сервере.

## Админ-панель

1. На стартовом экране выберите «Войти как администратор».
2. В шапке приложения появится кнопка «Админ» — она открывает панель управления.
3. В панели можно добавлять, редактировать и удалять новости, мероприятия, фотоотчеты, мерч, администраторов и партнёров.
4. Фото загружаются с телефона или компьютера и автоматически уменьшаются перед сохранением.
5. Кнопки «Скачать копию» и «Загрузить копию» переносят контент между устройствами, «Сбросить» возвращает исходный набор.

Сейчас контент хранится в localStorage браузера: изменения видны только на том устройстве, где их внесли. Для общей публикации на все телефоны нужен backend или GitHub-токен — это следующий этап.

## Включение GitHub Pages

1. Settings → General → Danger Zone → Change repository visibility → Public.
2. Settings → Pages → Source: Deploy from a branch.
3. Branch: main, folder: /(root), Save.
4. В этом же разделе появится Visit site. Публикация занимает несколько минут.

GitHub Free требует публичного репозитория для публикации Pages. Сам сайт и Issues с новостями будут публично доступны — никаких паролей, приватных фотографий, конфиденциальных сведений не публиковать.

## Что уже доступно

- Раздельный стартовый экран (участник / тестовый администратор);
- админ-панель: новости, мероприятия, фотоотчеты, мерч, администраторы и партнёры;
- новости через GitHub Issues, без переустановки приложения;
- календарь, фотоотчеты, «Наши админы» (пока примеры);
- мобильный дизайн в JDM-стиле с сакурой и поддержка установки как PWA.

## Ограничения теста

Нет реальной авторизации администратора, собственного backend, серверной базы, push-уведомлений и общей синхронизации контента между устройствами: правки админ-панели сохраняются локально в браузере и переносятся через экспорт/импорт JSON. GitHub API имеет лимиты обращения. Тестовая страница упрощена относительно подготовленной офлайн-сборки v0.2; фирменные изображения продолжим подключать отдельно.
