# Маркообразные Новосибирск — клубное PWA

Приложение автоклуба «Маркообразные Новосибирск»: новости, встречи, фотоотчёты,
мерч, администраторы и партнёры.

Живая версия: https://elizawetach.github.io/markoobraznye-nsk/

## Как устроено

- **Фронтенд** — статический сайт на GitHub Pages: `index.html`, `style.css`,
  `app.js`, `admin.js`, `content.js`. Сборка не требуется.
- **База** — Supabase (Postgres, Auth, Storage, Realtime).
- **Контент** — таблица `public.content`: одна строка на раздел (`news`,
  `events`, `photos`, `merch`, `admins`, `partners`), внутри `items` — JSON-массив
  записей. Изменения сразу приходят на открытые устройства через Realtime.
- **Фото** — публичный bucket `media` в Supabase Storage. Перед загрузкой
  изображения уменьшаются до 1280 px в браузере.
- **Доступ** — e-mail и пароль Supabase Auth. Список редакторов хранится в
  `public.editors`; первый вошедший становится владельцем клуба.
- В `content.js` лежит только публикуемый (publishable) ключ Supabase. Секретный
  `service_role` ключ в репозиторий не попадает.

## Установка на телефон

- **Android / Chrome**: меню → «Установить приложение» или «Добавить на главный экран».
- **iPhone / Safari**: «Поделиться» → «На экран Домой» → «Добавить».

Приложение работает как PWA: отдельная иконка, полноэкранный режим и офлайн-копия
последних загруженных данных.

## Админ-панель

1. На стартовом экране выберите «Войти как администратор».
2. После входа в шапке появится кнопка «Админ».
3. В панели можно добавлять, редактировать и удалять новости, мероприятия,
   фотоотчёты, мерч, администраторов и партнёров.
4. Изменения сохраняются в общей базе и сразу видны всем участникам и другим
   администраторам.
5. «Скачать копию» и «Загрузить копию» — резервная копия контента в JSON.
   «Сбросить» возвращает исходный набор разделов.

Новых администраторов добавляют в таблицу `public.editors` (SQL Editor или
service_role). Подробности — в `supabase/README.md`.

## Публикация сайта

Репозиторий: `ElizawetaCh/markoobraznye-nsk`, ветка `main`, GitHub Pages из корня.
После изменения файлов достаточно отправить их в `main` — Pages пересоберёт сайт
за несколько минут. Пути в приложении относительные, поэтому переезд на свой
домен не требует правок кода.

## Структура

```
index.html            разметка приложения и диалогов
style.css             оформление (сакура, самураи, JDM)
app.js                публичные разделы и диалоги
admin.js              админ-панель
content.js            Supabase, авторизация, синхронизация, Storage
merch-data.js         исходный набор мерча
photos-data.js        исходный набор фотоальбомов
social-qr.js          QR-коды соцсетей
install.js            установка PWA
sw.js                 service worker и офлайн-кэш
vendor/supabase.js    клиент Supabase
supabase/             схема и документация базы
assets/               логотип и фотографии
```
